Проект направлен на разработку веб-сервиса для создания HTML-шаблонов email-рассылок. Система позволяет формировать письма, выбирать сегменты получателей из 1С и тестировать рассылки через симуляцию отправки. Решение упрощает и ускоряет подготовку маркетинговых email-кампаний.

1C:
1С Предприятие - загрузочные файлы "1С:предприятие"
Конструктор HTML-рассылок.dt - конфигурация 1С

Файлы:
res - ресурсы
app.py - бэкенд
database.db - подключение к БД
index.html - основная страница сайта
sc.js - логика взаимодействия
style.css - стили сайта
